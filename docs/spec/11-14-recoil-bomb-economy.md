# 后坐力、掉包恢复与购买预算修复

日期：2026-11-14。状态：已随 `1114-v0.18` 提交（`main` v14 / `account2` v17 admission `passed` 并激活），实战效果待验证。

Submission: [1114-v0.18](../submissions/1114-v0.18/README.md)

## 后坐力补偿

`combat()` 改读合法武器字段 `recoil_yaw` / `recoil_pitch`，不再读取不存在的 `aim_punch`。
补偿沿用官方 JavaScript baseline 的 2 倍角度偏移：目标角度减去当前视角与两倍后坐力。
对准判定使用补偿后的误差；速度、可见性、扫射距离与中远距只点头 0.6 秒节奏保持原逻辑。
该系数有 baseline 依据，尚未用新对局证明命中率提升。

## 掉包恢复

仅 T 方、未携包、观测明确为 `bomb.state == "dropped"` 且提供位置时开始恢复。
掉包位置覆盖进攻路线与 40 秒去 CT 出生点兜底；用原有 A* 和移动恢复逻辑接近炸弹，依赖引擎的近距可见自动拾取。
遇可见敌人仍优先交火。CT 不追掉包，缺少合法位置时不猜测。

开始恢复后，本回合停用原有录制路线与进攻 via 点。自己捡包后直接寻路到合法下包位置；队友捡起后前往选定包点支援。
中断录制不计为路线完成，不增加成功权重；实际下包仍按原有成功规则记账。恢复标志在下一回合重置。

## 购买

按当前观测每拍购买一件，顺序为：缺主武器且买得起则买步枪；护甲低于 50 时买护甲；缺头盔且预算足够则买头盔；最后 CT 补拆弹器。
头盔预算门槛为满甲 350，否则 1000；有头盔不重复购买。
因此 CT 3000 元可先买 M4，800 元无甲开局先买护甲；充裕预算可连续买齐步枪、护甲、头盔、拆弹器。

## 验证

`tests/test_immediate_fixes.py` 覆盖非零后坐力的纠偏与开火、掉包覆盖录制/CT 兜底、拾取后的下包导航、队友拾取、换回合重置、交火优先、CT/未知位置边界，以及购买预算和连续购买。

运行完整回归：`python3 -m unittest discover -s tests`。账户测试需要允许本地回环端口。
