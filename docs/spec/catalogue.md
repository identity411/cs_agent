# 冻结武器与装备目录

> 依据：AGX「多人爆破 · AI 助手开发指南」中的「冻结购买与武器表」（合同 `rsi-fps-5.5`，数值取自 `rsi/games/fps_v53_weapons.py`、`rsi/games/fps_v53_utility.py`、`rsi/games/fps_v54_actions.py`）。这里只做摘要，实际购买与命中以裁判回执、护甲、部位和距离裁决为准。
>
> 完整冻结数据见 [`fps54-catalogue.json`](fps54-catalogue.json)（由官方 JSON 规范化键名为 camelCase，数值未改；`knife`、`utility_physics` 等顶层块保留原键名）。

## 槽位与计数

- 目录含 **24 个武器条目 = 23 种枪械 + 刀**；另有 **6 种可购买投掷物**。
- 目录槽位：`1` 主武器、`2` 副武器、`3` 刀。
- 动作槽位是另一套编号：`0` 主武器、`1` 副武器、`2` 刀。
- T / CT 指**当前进攻 / 防守职责**，不是永久队号。
- `c4` 由裁判发放，不可购买。
