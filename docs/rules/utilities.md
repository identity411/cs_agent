# 投掷物与道具判定

> 规则身份：`rsi-fps-5.5`。以下机制照搬 `cs2-web e0e7e858aec24c96c324113d7d91c9fce5085028` 的 `server/grenades.js` 与 `game.js`；5.4 的正式母版、平衡、盲写和容量证据不证明本规则通过。
>
> 道具价格、单回合上限与摘要见 [`../spec/catalogue.md`](../spec/catalogue.md)。

## 投掷出手

| 项目 | 判定 |
| --- | --- |
| 力度 | `full` / `lob` / `drop` = 1 / 0.5 / 0 |
| 俯仰修正 | `pitch` 限 ±1.48 后增加 `π/18 × (1 − abs(pitch)/(π/2))` |
| 眼高 | 站立 1.62 m / 蹲下 0.95 m；再减 `(1 − 力度) × 0.3` |
| 前移 | 0.35 m，受七射线 sweep 阻挡 |
| 初速度 | `750 × 0.0254 × 0.9 × (0.3 + 0.7 × 力度)`；继承速度 ×1.25 |
| 在飞上限 | 同时最多 40 个 |

## 飞行

- 每 60 Hz tick 两个 1/120 s 子步。
- 重力 8.128，分两半施加。
- 半径 0.06 m 的七射线 sweep；每子步最多 4 次碰撞。
- 镜面反射后全部速度 ×0.45。
- 地面法向 `z > 0.7` 且速度 < 1.2 m/s 时停稳。
- 超过 12 s 或 `z < −250` 移除。

## 烟与诱饵

- 烟雾弹 / 诱饵需过 2 s 引信且落稳才生效。
- 烟心向上抬 1.3 m；半径 4.5 m，寿命 18 s。
- 烟在 1.8 s 内按 `0.15 + 0.85 × (1 − (1 − 进度)^3)` 渐开。
- 最多 40 个烟、20 个诱饵。
- 诱饵每 900 ms 发声一次；到期时造成 5 伤害，半径 2 m。

## 烟洞

| 武器 | 烟洞半径 |
| --- | --- |
| AWP / SSG08 | 0.35 m |
| AK47 / M4A1 / M4A4 / GalilAR / Famas / AUG / SG553 | 0.24 m |
| 其余武器 | 0.18 m |

- 子弹烟洞持续 0.7 s，最后 0.25 s 线性恢复。
- HE 烟洞 3.5 m；若爆点距烟心 < 2 m，取 `max(3.5, 烟半径 + 0.5)`；持续 2.5 s，最后 0.6 s 按 `1 − 恢复进度²` 恢复。
- 烟内弦取五个采样点，必须全部在洞内才通视。
- 源码只对子弹追加做超过 30 个时移除首洞；HE 追加没有截断。

## 火

- 燃烧瓶 / 燃烧弹：地面法向 `z > 0.7` 时立即点火。
- 3.5 s 到时仍在空中则为 `fire_failed`。
- 固定六环、LCG 种子、探地与视线筛选，最多 60 格；最多 12 火。
- 水平距离某格 < 0.75 m、脚在格高 −0.4 至 +1.3 m 的严格区间且视线通，每 200 ms 扣 8 伤害；火不被护甲吸收。

## 灭火

- 每 tick 逐格检查格上 0.4 m 是否在**未过期烟的完整半径**内；烟刚开始渐开也灭火。
- 新火落入已有烟立即熄灭。
- 不以烟洞或视觉渐开缩小灭火半径。

## 闪光

- 量到眼睛；距离 < 30 m 且无遮挡，`d = 1 − 距离/30`。
- `dot > 0.5`：`hold = 2.2d`、`fade = 2.3d`、`alpha = 1`。
- `−0.2 < dot ≤ 0.5`：`f = (dot + 0.2)/0.7`，`hold = 0.8fd`、`fade = 1.8d`、`alpha = 0.5 + 0.5f`。
- 背对：`hold = 0`、`fade = 0.6d`、`alpha = 0.4d`。
- 总时长 > 0.05 s 才生效。
- 闪光在 `hold + fade` 全部期间禁止看见敌人（包含近身），不再缩成 2 m 视距。
- 多闪的致盲结束取最长 deadline，对应曲线随该次记录。

## 伤害与阵营

- HE 和火只伤敌人及投掷者本人。
- HE 伤害 `99 × (1 − 距离/8.9)`；距离和遮挡均量脚 + 0.9 m 处。
- 火伤害每 200 ms 8 点，见上。

## 时限与记录

- 所有 deadline 向上取整到首个满足的 60 Hz tick；决策仍为 20 Hz。
- 录像记录投掷物每子步轨迹、烟创建时刻及洞、火格变更、闪光 `exposure / hold / fade / alpha`。
- 前端只按记录时间插值与播放，不再模拟重力 / 反弹，也不预测未来落点。
- 受限视角不得使用下一帧的隐藏轨迹。
