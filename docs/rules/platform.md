# AGX 平台参赛规则

> 来源：AGX 官网「新手入门」页（2026-11-12 摘录整理）。具体比赛的规则以各比赛页面为准。

## 四步开始参赛

1. **选一场比赛**：打开比赛，查看目标、计分方式和提交语言。
2. **读规则**：下载示例，确认程序能收到的观测、可以返回的动作和资源上限。
3. **在自己电脑上开发**：
   - 坦克和德州使用 JavaScript；
   - 厨房、RTS、枪战、赛车与五场工程仿真使用 Python；
   - Python 文件的打包方法见官方「Python 提交指南」。
4. **报名、上传、看结果**：登录后在比赛页面报名并上传代码。游戏程序通过运行检查后自动参赛；工程提交由平台重新评测。在「我的比赛」查看结果和版本。

## 轮次与版本

- 游戏比赛按轮自动进行，每轮最多一局；轮次间隔见比赛页面。
- 上传的新版本从下一轮开始生效；已经锁定的对局保留原版本。
- 如果上一局还没结束，会跳过一轮，下一轮照常进行。
- 上传后持续参赛，不支持暂停。

## 账号与 API 密钥

- 网页报名和上传不需要 API 密钥。
- 自己的脚本需要密钥时，在账号设置中创建。
- 密钥只显示一次；轮换会立即使旧密钥失效。
- 端点与重试方式见官方「接入文档」。

## 计分与回放

- 每场比赛说明自己的计分方式。
- 游戏榜单按已结算对局更新；工程赛按题目规定的指标排名。
- 并列和作废的处理见各赛规则。
- 在「回放」查看公开对局；在自己的单局页面可下载有权限的训练数据。
- 公开回放不含私有决策轨迹；上传检查通过也不保证整局不会出错。

## 怎么选赛、多久一局

只列出当前公开的比赛。表中的时长是模拟时间或手数；排队和结算可能更久，轮次间隔不保证一局会在下一轮前结束。

| 比赛 | 策略能力与赛题 | 一局多长 | 多久一轮 |
| --- | --- | --- | --- |
| 多人坦克大战 | 命令队列、地形与资源争夺 | 最多 120 秒模拟时间 | 每 5 分钟 |
| 多人德州扑克 | 不完全信息与下注决策 | 240 手，六个换座阶段；无固定模拟分钟数 | 每 10 分钟 |
| 多人枪战：爆破模式 | 团队攻防与回合经济 | 每半场 12 回合，先到 13 胜；最多 24 回合，12:12 平局 | 每 2 小时 |
| 多人合作厨房 | 合作分工与任务调度 | 三关连班，共 630 秒模拟时间 | 每小时 |
| 多人即时战略 | 采集、扩张与多兵种调度 | 新规则：最多 10 分钟模拟时间 | 每小时 |
| 多人赛车 | 路线规划、驾驶与进站 | 十车排位后进行四圈正赛 | 每 2 小时 |

| 机械臂装配 | 控制七自由度机械臂完成接触受限的精密装配，并稳定满足力学约束。 |
| 芯片热设计 | 设计三维导热嵌件降低双热源封装的最坏峰值温升，并通过数值合格检查。 |

## 常见问题

- 为保证每轮分组整除，主办方可能派参赛者补位；成绩照常计算，具体是哪些账号不公开。

## API 参考

用脚本接入时，查看官方「接入文档」和 OpenAPI schema，了解端点、重试方式和错误码。
