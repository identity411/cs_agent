# 多人枪战：爆破模式

> 规则身份：`rsi-fps-5.5`。依据 AGX「多人爆破 · AI 助手开发指南」（2026-11-12）。原文说明这是闭门候选合同，是否适用以赛事与已接受投稿为准；历史对局保留自己的合同。
>
> 实测（2026-11-12）：`agx.cool` 的比赛 `2a97f94f-816a-52b7-b4b8-5925db160245` 使用 `game_id=fps`、`rules_version=rsi-fps-5.5`；Python 提交运行时为 `python-agent-v1`。游戏元数据里的 `example_code` / `baselines` 是 JavaScript 参考，不代表比赛提交语言。

## 队伍与席位

- 十个固定席位组成队伍 0（0–4）和队伍 1（5–9），各席 `role` 都是 0。
- 攻守交换不改变队伍、席位或策略进程。
- `side` 为 `attack` / `defend`；T / CT 指当前职责，不是永久队号。

## 赛制与结算

- MR12：每半场 12 回合，先得 13 胜者获胜，最多 24 回合。
- 第 12 回合结束后换边，清空装备，每席现金重置为 800；`round_index` 从 0 开始，下半场始于索引 12。
- 默认 `overtime_limit=0`，12:12 立即平局。MR3 加时（`overtime_half=3`）已实现但默认关闭；只有可信合同变更可以启用，策略不能启用。
- 胜队各席 `score=1`、`rank=0`；败队各席 `score=0`、`rank=1`。
- 平局十席 `score=0.5`、`rank=0`，按团队平局把 `[0,0]` 交给 OpenSkill；个人 mu、sigma、展示分仍可能变化。
- 现金、击杀与回合差不另加排名分。

## 时钟与决策边界

- 物理 60 Hz，策略决策 20 Hz（每三 tick 一次），公开录像 24 Hz。
- 决策边界先冻结十席合法观察，收齐并校验动作后才推进世界；非决策 tick 沿用上次动作。
- 每物理 tick 调用一次 `Arena.step`，由它安排策略调用；不要在循环里自行逐席调用策略。

## 阶段与回合流程

| 阶段 / 目标 | 规则 |
| --- | --- |
| `buy` 冻结 | 6 s / 360 tick；禁用战斗与目标操作 |
| `live` | 未安放情况下最多 115 s / 6900 tick 后超时 |
| `post` | 回合间 5 s / 300 tick |
| 购买 / 退款窗口 | 回合起点后 31 s / 1860 tick，含截止点；即冻结加 live 前 25 s |
| 安放 | 携带者在合法点连续 `use="plant"` 180 tick / 3 s |
| 拆除 | 连续 `use="defuse"`；有钳 300 tick，无钳 600；距离严格小于 2.8 m |
| 引信 | 安放后 40 s / 2400 tick；同 tick 拆除与引信到期时，到期优先 |
| 掉落炸弹 | 距离小于 2.3 m 且可见时自动拾取；主动丢弃者需等 90 tick |

- 安放前可因歼灭或未安放超时结束回合；安放后即使进攻方全部死亡，目标时钟仍继续。
- 成功拆除或爆炸结算；爆炸直接结束回合，不另加 HP 伤害。
- 目标交互期间锁定移动与开火，完成或解除后释放。
- 距离、视线与交互均由裁判判定；请求合法不代表一定成功。

## 目标交互条件

- 执行者必须存活、着地且速度不超过 0.1 m/s，持续对应 `use` 并满足包点 / 职责 / 距离条件。
- 忙于开火、装填、投掷或切枪的动作不能推进。
- Arena 会先选择并锁定合格执行者、抑制冲突控制，条件失效则中断进度。
- 多个新的拆除者按席位顺序选择，不按最近距离。
- 首次拆除候选要通过交互视线检查。
- 站点 `center` 是公开几何锚点，不是从任意出生点可直接到达的路线；安放由裁判判断脚点是否在站点 / `plant_zones` 内。

## 经济与库存

- 服务端选择 `ECONOMY_RULES=BALANCED`，参赛者不能通过 `config`、`design` 或动作修改。
- 现金上限 16000；开局与下半场现金均为 800。
- 普通回合保留现金；存活者保留允许装备，死亡者失去装备。
- 当前候选在新回合为保留枪械补满弹药，并重置武器就绪与后坐时钟。
- 半场重置对存活者同样清空库存，再发默认手枪 / 刀，并重置败补档位。
- 每次转换后以实际 `me.slots`、`me.weapons` 与回执为准。

### 收支

| 交易 | 金额或条件 |
| --- | --- |
| 普通回合胜利 | 胜队每席 3250 |
| 爆炸 / 拆除获胜 | 胜队每席 3500 |
| 败补档 | 1400 / 1900 / 2400 / 2900 / 3400；初始索引 1，首败发 1900 |
| 档位更新 | 结算后败队升一档、胜队降一档，限于索引 0–4 |
| 个人安放 / 拆除 | 300 / 300 |
| 安放后被拆，进攻方失败 | 进攻方每席额外 600 |
| 未安放超时且存活的进攻者 | 无普通败款 |
| 击杀 | 按武器，冻结目录及权威现金账本为准 |

## 购买与退款

- 要求玩家存活、处于己方出生购买区、窗口未关且目录物品符合阵营限制。
- 退款还需对应的合资格购买记录；重复请求不会重复发钱。
- 三武器槽为主武器 / 副武器 / 刀（动作槽 0/1/2）；目录含 23 把枪 + 刀，以及六类可购买投掷物。
- 使用 `ak47`、`m4a1`、`defusekit`、`hegrenade` 等具体 ID，不沿用旧的泛称武器名。
- 库存物品句柄是不透明标识，不能从中解析种子或未来信息；拾取 / 退款回执里的唯一 `item_id` 与武器种类不同。
- 价格、阵营限制、道具限额与武器时钟见 [`../spec/fps54-catalogue.json`](../spec/fps54-catalogue.json)。

## 地图与观察

地图池、选图、地图缓存与导航边界见 [`../spec/maps.md`](../spec/maps.md)；合法观察字段与信息边界见 [`../spec/agent-interface.md`](../spec/agent-interface.md)。

## 边界情况

- 12:12 只有在完整打完时才是平局；截断或被杀的任务不能算平局。
- 爆炸立即结束回合，不另加 HP 伤害。
- 同 tick 拆除完成与引信到期，引信到期优先。
- 安放后进攻方全灭，引信继续。
- 未安放超时且存活的进攻方没有普通败款。
- 默认无加时；12:12 立即平局。
